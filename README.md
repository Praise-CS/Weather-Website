## Steps to set up and run the application 

1. To start up the application for the you can run it from index.html

2. You can use the search bar to search for any city and then use the search button to search 

3. When you search it will diplay the temperature , favourite button , 7-day forcast button 

4. When you favourite a city you can then use the desktop or hamburger nav (Three lines) to get to the favourite webpage

5. If you want to view the 7 day forcast press the 7 day forcast button or use the desktop or hamburger link 

6. To go thru the pages use the hamburger of desktop navs

## Features 

1. Current Temperature of city

2. 7 day Forcast 

3. Favourite Cities 

## API

I used the Open meteo API to get the information for the current data and 7 day forcast data. 
Base URL: https://open-meteo.com/ . 
URl:https://api.open-meteo.com/v1/forecast?latitude=${latitude}&longitude=${longitude}&current=temperature_2m&daily=temperature_2m_max,temperature_2m_min&timezone=auto
